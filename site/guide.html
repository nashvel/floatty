01 / BEFORE YOU START

A Linux desktop.

You need Python 3.10+ with Tk 8.6, an X11 or XWayland display, GTK3 / VTE 2.91, and Codex CLI on your PATH. A compositor enables translucency.

ss inspects listening ports. notify-send handles notifications. Docker is optional; the app only targets a local daemon.

Native Wayland layer-shell, background blur, Windows, and macOS support are not implemented.
02 / GET IT RUNNING

From source to island.

1. Install native packages

On Ubuntu or Debian:

sudo apt update
sudo apt install python3-tk libvte-2.91-0 iproute2 libnotify-bin

Use the equivalent packages on other distributions. No pip packages or virtual environment are required.

2. Bring your Codex CLI

Follow the official installation guide, then sign in from a normal terminal with codex login. The island uses that existing sign-in.

3. Clone and launch

git clone https://github.com/nashvel/codex-island.git
cd codex-island
./launch.sh --folder /path/to/your/project

Replace /path/to/your/project with your project directory. Click the pill, then press Launch Codex. Choosing a folder does not launch anything.

4. Add it to your app menu

python3 scripts/install_launcher.py --folder /path/to/your/project

Search for Floatty in your desktop launcher. Reinstall the shortcut if you move the checkout. No sudo and no automatic startup.

03 / FIND YOUR FLOW

A few simple controls.

Click / drag the header
Expand, collapse, or reposition the island.
Folder
Browse or paste a project path. Cancel and slow folder loading keep the GUI responsive.
Ctrl+C
Interrupt inside the native terminal. Manually exit Codex before closing or changing folders.
Ctrl+Shift+C / V
Copy selected terminal text or paste.
Services → Stop
Confirm stopping the selected local service. Unknown owners and protected processes are read-only.
Motion / Opacity
Switch animations off and adjust the window’s transparency.
Completion notifications apply to CLI sessions launched inside the island. External terminals are not attached.
04 / NEED A HAND?

Check the basics.

The window or terminal won’t open

Run from an X11/XWayland desktop session. Check Tk and the GTK3 VTE runtime are installed. Launch ./launch.sh from a terminal to see startup errors.

Codex won’t launch

Check codex --version, complete your sign-in, and select an existing folder. The app displays the executable it will run above the terminal.

A service can’t be stopped

Check local daemon permissions for Docker. Port processes need same-user ownership and Linux pidfd support. Protected or unknown owners stay read-only; a supervisor may restart a stopped service.

I don’t receive notifications

Enable Notify when done and check that notify-send and your desktop notification daemon work. CLI exit and task completion are different events.

Still stuck? Report a reproducible issue with your Linux distribution, desktop, Python and Codex versions. Redact private terminal content.
