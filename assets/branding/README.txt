Linux user icon installation example:
mkdir -p ~/.local/share/icons/hicolor/256x256/apps
cp codex-island-256.png ~/.local/share/icons/hicolor/256x256/apps/codex-island.png

For a desktop file set Icon=codex-island and update Exec to the real executable path.
